
# KeivenAPP

Aplicación desarrollada en Flutter para la asignatura de Aplicaciones Móviles de Unitecnar.

## Descripción

KeivenAPP es una aplicación sencilla que permite interactuar con un contador mediante tres botones.

## Funcionalidades

- **Sumar:** aumenta el contador en una unidad.
- **Restar:** disminuye el contador sin permitir valores negativos.
- **Reiniciar:** devuelve el contador a cero.

## Tecnologías utilizadas

- Flutter
- Dart
- Visual Studio Code
